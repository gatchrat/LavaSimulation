# Lava Simulation

Made for the Course "Game Lab" at the Technische Hochschule Brandenburg as a group Projekt together with León Encarnação.
Compares different Methods of Fluid Simulation, this upload mainly contains a SPH based approach due to filesize limitations for the other approaches.
